Onkyo — Verified
تنظیمات صدا — مطابق RC-332S / CR-185
دفترچه: TONE برای BAS/TRE/BAL، بازه Bass/Treble از −10 تا +10 و Balance از L3 تا R3؛ S.BASS و DIRECT نیز در ریموت اصلی هستند. کدهای این سه کلید در بانک فعلی هنوز Verified نشده‌اند، بنابراین با Safe Candidate وارد Code Lab می‌شوند.
Sony — Default Candidates
این‌ها «کد قطعی CMT-E300HD» نیستند. از جدول عمومی SIRC گرفته شده‌اند و فقط به‌عنوان نامزد اولیه قرار گرفته‌اند: Volume+/−، Mute و Power با Commandهای رایج 18/19/20/21 و Addressهای صوتی 16 و 17. هر مورد بعد از تست باید Verify شود.
تنظیمات صدا — مطابق CMT-E300HD / RM-E02D
دفترچه CMT-E300HD کلیدهای M.BASS و Preset EQ را روی ریموت مشخص می‌کند. چون command اختصاصی RM-E02D برای این مدل از منبع معتبر به‌دست نیامده، این کنترل‌ها به‌صورت Candidate وارد Code Lab می‌شوند و بعد از کارکرد باید VERIFIED شوند.
Victor/JVC — Safe Code Lab
JVC قالب 37.9kHz و Custom/Data هشت‌بیتی را مستند کرده، اما جدول NX-TC5 اختصاصی پیدا نشده است. بنابراین کد مدل را جعل نکرده‌ایم؛ آزمایش دستی/اسکن امن از اینجا انجام می‌شود.
تنظیمات صدا — مطابق NX-TC5-B / RM-SNXTC5-S
دفترچه رسمی JVC: AHB PRO روشن/خاموش می‌شود؛ Sound Mode شامل Manual EQ، Live، Rock، Pop، Classic و Dance است. Manual EQ: Treble −5..+5 و Bass −5..+5. این کلیدها تا کشف Custom/Data مدل در Code Lab نگه داشته می‌شوند.
Code Lab — ارسال دستی
برای SONY: A=Address، B=12/15/20، C=Command. برای JVC: A=Custom، C=Data، B نادیده گرفته می‌شود.
